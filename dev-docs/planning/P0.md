# 第三刀：先定义最重要的抽象

这个我认为是整个新版最值得先定死的地方：

```ts
export interface AgentTask {
  prompt: string
}

export interface AgentResult {
  output: string
}

export interface AgentExecutor {
  execute(task: AgentTask): Promise<AgentResult>
}
```

也就是你开发计划里提到的：

```text
workflow
   ↓
AgentExecutor
   ↓
OpenCodeV2Executor
   ↓
ctx.session
```

而不是：

```text
agent()
  ↓
直接 ctx.session.xxx()
```

这个隔离非常重要，因为它决定了未来你的 Core 是：

```text
Agentic Workflow Engine
```

而不是：

```text
一堆 OpenCode API wrapper
```

你文档里已经提出未来甚至可以实现 `OpenCodeExecutor / ClaudeCodeExecutor / CodexExecutor / PiAgentExecutor`。开发计划

第一版甚至可以：

```ts
export class MockExecutor implements AgentExecutor {
  async execute(task: AgentTask) {
    return {
      output: `[mock] ${task.prompt}`,

  }
}
```

先完全脱离 OpenCode 测 workflow core。

# 第四刀：实现最小 `agent()`

不要让 `agent()` 知道 `ctx`。

```ts
let executor: AgentExecutor

export function setExecutor(value: AgentExecutor) {

}

export async function agent(prompt: string) {
  return executor.execute({
    prompt,
  })
}
```

这样：

```ts
await agent("分析登录模块")
```

实际上执行：

```text
agent()

OpenCodeV2Executor
   ↓
OpenCode Session
```

这里先不要实现：

```text

retry

verify
token metrics
context isolation
```

全部以后再加。

# 第五刀：实现 `parallel()`

第一版可以极其简单：

```ts
export async function parallel<T>(
  tasks: Array<() => Promise<T>>
): Promise<T[]> {
  return Promise.all(
    tasks.map(task => task())
  )
}
```

测试：

```ts
const result = await parallel([
  () => agent("分析 A"),
  () => agent("分析 B"),
  () => agent("分析 C"),
])
```

# 第六刀：实现 `sequence()`

同样先保持简单。

```ts
export async function sequence<T>(
  steps: Array<(prev?: T) => Promise<T>>
) {
  let result: T | undefined

  for (const step of steps) {
    result = await step(result)
  }

  return result
}
```

第一版的语义只需要：

```text
Step A
  ↓
Step B
  ↓
Step C
```

暂时不要混入：

```text
failure strategy
jump
fallback
retry
checkpoint
branch
```

这些等 P1。

到这里前面所有东西都应该通过 Mock Test。

```text
                    Workflow Core

                         agent()
                            │
                            ▼
                     AgentExecutor
                            │
                            ▼
                 OpenCodeV2Executor
                            │
                            ▼
```

V2 官方的设计本身也正适合这么做，因为很多能力已经围绕 `ctx.session`、`ctx.permission`、`ctx.agent`、`ctx.storage` 等 domain 暴露，不再像 V1 那样集中在单独的 `client` 上。[OpenCode](https://opencode.ai/v2/docs/build/plugins/migrate-v1?utm_source=chatgpt.com)

> **只有 OpenCodeV2Executor 可以碰 OpenCode API。**

不要让：

```text

sequence.ts
agent.ts
engine.ts
```

到处出现：

```ts
ctx.session
ctx.agent
ctx.permission
```
