# 宿主 2.0.26 会话作用域 slot：主页无挂载点 + PTY 探针取证法

> 2026-10-09 · 0.7.0 发布后用户报告「重启 opencode 面板没默认打开」· 定位全程
> 无头复现（PTY 探针），占用用户一次重启验证

## 现象

用户升级 0.7.0 后重启 opencode（宿主 brew 同日升到 **2.0.26**），报告「没有默认
打开 TUI」。同期用户确实跑了两个 run（journal 佐证 13:58/13:59 completed）。

## 取证过程（日志三层排除 + PTY 四探针）

1. **日志无插件失败**：`plugin operation failed` / ERROR 均无——排除 setup 崩溃
   （0.5.0 时代 keymap 坑的失败样式没有复现）
2. **缓存版本正确**：`~/.cache/opencode/npm/@mickorz/...@latest/` 解析 0.7.0，
   排除进程冻结/旧版本
3. **PTY 探针**（`python3 pty.fork()` + 按键注入 + ANSI 抓帧，脚本在
   `/tmp/opencode/tui-probe*.py` 思路）：
   - 探针1：主页敲 `/workflow` → **命令菜单出现 "/workflow Workflow progress"**
     → 插件装载正常
   - 探针2：会话内自然语言跑 calc → **面板自动弹 + 全部 0.7.0 特性渲染**
     （`· 1 running` 头行后缀、`25.6k tok`、`glm/glm-5.3-flash` 步骤后缀、
     历史 run 列表）→ 会话内一切正常
   - 探针3：异常样本（run 完成但无面板标记）——输入没进会话视图时
     `panel.open` 同样落空，佐证下面根因
   - 探针4：**主页静置 20s——插件零渲染痕迹**

## 根因

宿主 2.0.26 的挂载点作用域（官方 CLI 插件文档明示）：

| 挂载点 | 作用域 |
|---|---|
| `session.panel` | **仅会话内**；「Opening outside a session returns `false`」 |
| `sidebar.content` / `sidebar.footer` | 仅会话内（input 带 sessionID） |
| `prompt.footer(.status/.file)` | 仅会话内（输入框存在才有） |
| `home.footer` / `home.footer.status` | **主页**（唯一主页挂载点） |
| `app` / `ui.router` / `ui.dialog` | 全局 |

v1 的 sidebar_content 是全局组件，主页也渲染——v2 重写后所有"进度可见性"
slot 都绑会话。**重启后停在主页（New session）→ 什么都不显示**，与用户
「默认打开」的期望（v1 记忆）正好落空。会话内行为无回归。

## 修复（0.7.1）

`home.footer.status` 追加常驻行（主页唯一挂载点，官方语义：排在健康指示器后、
版本号前）：

- 有 run 在跑：`◐ N running · flow@ver`（warning 色）
- 无运行：`▶/✓ flow@ver · status`（muted 色，最近一条 run）
- 空板：不渲染

重启第一屏即有 workflow 痕迹；进会话后原有三件套（面板自动弹/侧边栏/
输入框状态条）不变。

## 方法论沉淀：PTY 探针取证法

TUI 插件问题全自动化 E2E 覆盖不到（`opencode run` 只走 server 入口——
0.5.0 坑的教训）。PTY 探针补位：

```python
pid, fd = pty.fork()          # 子进程 execvp("opencode", ["opencode"])
# 父进程 select 轮询读帧 + os.write(fd, b"/workflow\r") 注入按键
# ANSI 剥离后在字节流里找渲染标记（面板标题/行文本）
```

注意两点：
- **帧差渲染会打碎字符串**：增量帧只重绘变化单元格，`"── detail"` 这类长串
  可能分散在多帧里 substring 搜不到；全量重绘帧（面板刚打开）才是可靠证据。
  需要精确验证时上终端模拟器（pyte）重建屏幕态，别信裸字节流
- **杀进程要限定范围**：`os.kill(pid, SIGTERM)` 只杀探针子进程；
  全局 `pkill opencode` 会误杀用户实例和宿主

## 对批次 C 的设计影响

全屏工作流视图别走 session.panel fullscreen（会话作用域，主页进不去）——
走 `ui.router.register` 全局路由 + `/workflow` 命令导航，主页/会话内都能进。
