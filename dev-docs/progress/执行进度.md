## 环境约束（必须遵守）

- 模型 API 最多 **3 个并发**（已由 `withConcurrencyLimit` 默认值保障）
- 验收前先预检模型可用性；`opencode run` 一律带看门狗超时
- 免费档配额全局共享，失败重跑前先查 `/api/session` 定位根因
