## P2.5 交付清单（Commit 17）

**Registry（定义 + 注册表 + 版本身份 + args schema + journal 集成 + 插件路由）**

- `src/registry/definition.ts`：`WorkflowDefinition<TArgs, TResult>`（id/version/description/argsSchema/stepNames/run）+ `WorkflowContext`（runId + mode:start|resume + journal + **runSteps 注入入口**——start/resume 差异被 ctx 完全封装）+ `defineWorkflow` 类型糖
- `src/registry/registry.ts`：`WorkflowRegistry`
  - 同 id 多版本共存；同 id+version 重复注册抛错；缺 id/version 拒绝注册
  - `get(id)` 取最新（semver 最高，非 semver 按注册序殿后）；`get(id, version)` **精确命中**
  - `resolve(id, version?)` 严格版：未命中抛 `WorkflowNotFoundError` 并列出可用版本（resume 诊断友好）
  - `versions/latest/ids/listLatest/summarize`（工具枚举与描述驱动）
- `src/registry/schema.ts`：`ArgsSchema`（最小 JSON Schema 子集，零依赖不引 Zod）+ `validateArgs`（type/required/properties/enum/items，嵌套+联合）
- `src/registry/errors.ts`：`WorkflowRegistrationError` / `WorkflowNotFoundError` / `WorkflowArgsError` / `WorkflowExecutionError`（携带 runId，全家族继承 WorkflowError）
- `src/registry/runner.ts`（journal 集成核心）：
  - `startWorkflow(registry, store, id, args, {version?})`：resolve → args 校验 → journal 落盘（`workflow: {id, version}` + args + stepNames）→ `definition.run(args, ctx{mode:start})`；成功/失败均收口 journal；失败抛 WorkflowExecutionError(runId)
  - `resumeWorkflow(registry, store, runId)`：journal → **精确版本解析**（绝不隐式取最新）→ args 取 journal → `definition.run(args, ctx{mode:resume})`（runSteps=resumeSequence）；completed run 幂等重放（零步骤执行）
  - `runWorkflowInline(registry, id, args)`：未配 journalDir 的直跑兼容路径
- **WorkflowRun 模型升级**：`workflowId: string` → `workflow: {id, version}`（安全 resume 的身份依据）；args 放宽为 `unknown`；时间戳保持 epoch ms（排序/耗时计算不变）
- **workflow 层重构（resume 正确性关键）**：步骤状态从闭包捕获改为 **prev 链累积**（`{...prev, 新字段}`）——resume 跳过 completed 步骤后，最终报告仍能从 journal 记录的累积状态完整重建；`runReliableWorkflow`/`runSmokeWorkflow` 接受可选 `runSteps` 注入（缺省 sequence 直跑，全部既有测试不受影响）；smoke 步骤化（research/summary 两步，可恢复）
- `src/workflows/{smoke,reliable}.ts`：声明式定义（含 argsSchema + stepNames），新增 workflow = 新增定义文件 + 注册一行，零插件改动

## P2.2 交付清单（Commit 14）

- `sequence(steps, { journal })`：journal 感知执行——每步 `stepStarted(i, prev)` / `stepCompleted(i, output)` / `stepFailed(i, cause)` 落盘；run 级 `complete()/fail()` 收口（fail-fast 与 continue 模式均覆盖）
